MERGE SORT

A Divide and Conquer Algorithm
Sorted data is faster to search, compare and combine.

The idea in three steps

1. Divide

Split the array into smaller subarrays.

2. Conquer

Sort the small subarrays. One element is already sorted.

3. Merge

Combine sorted subarrays into one sorted array.

Divide the array

Merge and sort

The algorithm

O(n log n)Time in best, average and worst cases
O(n)Extra space for the temporary merged arrays
StableEqual values keep their original order
